## 1. 下载

打开微信官方文档站的下载页：

```
https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
```

- 选 **稳定版 Stable Build** → **Windows 64 位**
- ⚠️ **不要下 RC / Nightly 版**（不稳定，可能出各种莫名报错）

## 2. 安装 + 登录

- 一路默认安装即可。
- 打开后用**微信扫码登录**。
- ★ **必须用"管理员"那个微信号扫** —— 也就是你注册小游戏时用的那个。
  用别的微信号登录，**项目列表里看不到「疾风夺金」**。

## ⚠️ 别点错：「创建小游戏」≠「导入项目」

点 `+` 弹出的对话框，**标题会告诉你它到底是哪一个**：

| 标题 | 它干什么 | 特征 |
|---|---|---|
| ❌ **创建小游戏** | **新建一个空模板项目**（默认落在 `C:\Users\<用户名>\WeChatProjects\...`） | 有 **「模板选择」**（纯 JS 模式 / 其他模板）+ **「后端服务」**单选 |
| ✅ **导入项目** | 打开**你已经写好的**项目目录 | **只有三项**：项目名称 / 目录 / AppID，**没有模板选择** |

> 已经踩过一次：在「创建小游戏」里填了项目名和 AppID、目录却还留在 **C 盘**——
> 一旦点「创建」，得到的是一个**跟本项目毫无关系的空模板**。

**正确入口**：项目列表页 → **「导入项目」**（若它和"新建"是同一个弹窗的两个标签，切到「导入」那一栏）。

## 3. 导入项目（关键三步）

| 字段 | 填什么 | ⚠️ 易错点 |
|---|---|---|
| **目录** | 你本地存放本项目的**项目根目录** | ★ 必须选**项目根目录**（有 `game.js`、`game.json` 的那一层），不要选到 `js\` 或 `preview\` |
| **AppID** | ✅ **已替你预填** `wx88b969885dbea62d` | 若显示为空，回后台「设置 → 基本设置」复制 |
| **项目名称** | `疾风夺金`（默认会带出 `jifeng-duojin`，可改） | 不影响运行 |

- 若对话框里有 **项目类型** 选项 → 选 **小游戏**（通常已根据配置自动识别）。
- 点 **确定**。

> AppID 在哪：后台 → **设置 → 基本设置** → 复制 **AppID（`wx` 开头）**。

## 4. 打开后会看到什么

左侧出现**竖版模拟器**，依次是：

1. **启动页** —— 品牌标记 + 大字「疾 风 夺 金」+ 进度条
2. 自动进入**主页** —— 模式横排 chip、开始按钮、签到/商城/排行榜入口

**能走到第 2 步 = 导入成功。** 点「开始」能玩（单指左右拖动躲红块）就说明运行链路通了。

## 5. 可能遇到的报错（对照着看）

| 现象 | 原因 | 怎么办 |
|---|---|---|
| **"AppID 无效"** | AppID 填错 / 没换掉占位符 | 回后台复制完整的一串，重开导入对话框 |
| **"不是该小游戏的开发者"** | 扫码的微信号不是管理员 | 用管理员微信号登录；或去后台「添加开发者」把自己加上 |
| **云开发相关报错**（环境不存在 / 函数未部署） | **你还没开通云开发** | **这是正常的，先不管** —— 排行榜会自动降级成"本地/离线"。游戏本体照常能玩 |
| **白屏 / 卡在启动页** | 代码或配置问题 | 打开工具底部 **调试器 → Console**，把**第一条红色报错**截图发我 |
| **提示基础库版本** | 配置里写的是 `3.0.0` | 保持默认即可，或选最新稳定版，一般不影响 |

> ⚠️ **云开发那几个报错是"预期内"的**，别被吓到。开通云开发是**下一步**。
